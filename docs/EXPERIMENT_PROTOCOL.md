# 前向きシャドー実験プロトコル v1.0

## 1. 目的

危機予報器として不採用となったR4分類器と市場ブラックホール（BH）補助層を、売買判断から切り離した状態監視器として前向きに記録する。

## 2. 固定事項

- 基準日: 2026-07-31
- R4のWalk-forward ROC-AUC: 0.623（報告値）
- R4のイベント再現率: 33.3%（報告値）
- R4の誤警報: 年0.477回（報告値）
- BH coreのAP: 0.152、R4同一環境AP: 0.154
- BH表現固有の予測優位は確認されていない
- M / K / J(H) / D_EH は説明・状態監視用の二次層としてのみ保存する

## 3. 状態規則

- `STABLE`: リスク・パーセンタイル < 0.50
- `WATCH`: 0.50以上0.65未満
- `WARNING`: 0.65以上だが`CRITICAL`条件を満たさない
- `CRITICAL`: 0.85以上が直近5観測のうち3観測以上、かつ`ACTIVE_CRISIS`外
- `ACTIVE_CRISIS`: 252営業日ピークからの下落が8%以上
- `UNSCORABLE`: スコア不能またはデータ品質が不足

## 4. 危機イベント

S&P 500の252営業日ピークから12%下落への交差を危機イベントとする。60観測のクールダウンで重複を抑える。交差前60観測を予報窓とし、その中の`CRITICAL`を捕捉として扱う。

## 5. 台帳規則

- 観測日は一意
- 同一日の上書きを禁止
- 日付の逆行を禁止
- 入力JSONのSHA-256を保存
- 過去行を結果判明後に変更しない

## 6. 再判定条件

「独立した新規危機2件」と「5年経過」の両方を満たした後にのみ採否を再評価する。採用には未使用期間で、再現率50%以上、誤警報年1回以下、循環シフトp<0.05、年代安定性5/7相当を同時に要求する。

## 7. 現在の制約

旧実験の完全な学習済みモデル、1990-01-02〜2026-07-31の保存データ、特徴量生成コード、`uv.lock`がこの新規リポジトリには存在しない。復元前に新規学習を行うと「仕様凍結」に反するため、本実装はスコアの生成と受け入れを分離している。
